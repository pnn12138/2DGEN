# configI/配置信息
概述：本目录用于管理**实验配置**基于 [Hydra](https://hydra.cc/) 实现可组合、可拓展的配置系统。  
核心理念：**把“代码逻辑”和“实验超参 / 数据 / 模型配置”解耦**，方便后期扩展到更多数据集、模型与任务。
当前项目主要面向 **二维材料性质预测**，首个任务是 **JARVIS-DFT 的 `Jdft2d` 剥离能回归**，后续会扩展到 C2DB 稳定性、2D 力学性质、多任务等。

# 目录架构
conf/
  README.md             # 当前说明文档

  data/                 # 数据集与数据加载相关配置
  model/                # 模型结构与超参数配置
  trainer/              # 训练循环、优化器、调度器等配置
  loss/                 # 任务级别配置（loss、metrics、输出目标等）
  logging/              # 日志、输出目录、可视化工具配置
  callbacks/            # 早停、保存最佳模型等（可选，后续扩展）
  
  Jdft2d.yaml           #Jdft2d预测任务的参数（不同任务的Hydra 入口）
